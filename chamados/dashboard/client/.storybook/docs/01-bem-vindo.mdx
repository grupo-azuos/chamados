# Azuos · Design System

Este é o catálogo dos componentes do **Chamados**, feito sobre o **template** do Grupo Azuos — a
base de onde nascem todos os sistemas. Tudo o que aparece aqui é o que o sistema usa de verdade:
os componentes seguem os do template, só que escritos em Svelte.

O visual é um só, o **padrão Apple**: superfícies limpas, sem borda, cantos grandes, sombra
difusa, botões em pílula, a fonte do sistema e a cor de cada assunto num ícone cheio. Ele só
troca entre **claro** e **escuro (grafite)** — use o botão **Tema** na barra de cima para ver os
dois.

## Como usar este catálogo

- **Introdução e Fundamentos** explicam as regras: cores, forma, tipografia e como organizar uma
  tela. Leia antes de montar uma tela nova.
- **Components** reúne os componentes genéricos (`lib/components/azuos-*`), e **Features** os de
  cada tela (`routes/<feature>/components/azuos-*`), agrupados pela feature.
- A aba **Docs** de cada componente começa pelo que importa para escolher: **para que serve,
  quando usar e quando não usar** (e o que usar no lugar). Depois vêm o exemplo, as props, como
  ele funciona por dentro e todas as variações.
- A aba **Accessibility** mostra o contraste e o foco: a equipe usa o sistema no teclado o dia
  inteiro.

## Onde mais isto aparece

- O app **Marca** (brand) mostra a identidade, os documentos e leva para este catálogo.
- As regras completas estão em `.claude/rules/design-governance.md` do template, e
  o check de design (`mise run design:check`) confere o que dá para conferir no código.

## Quero um componente que não existe

Componente novo e dependência visual nova só entram no **template** (nunca direto num sistema).
Siga a skill `ui-component`: prefixo `azuos-`, props em `data`, `ui`, `state`, `actions`, uma
story `.stories.svelte` com as variações e o texto dele em `.storybook/component-docs.ts`.
